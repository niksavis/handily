- **The message tab structures a message with numbered lines.** A message from another session
  with lines that start with `1.` turned every plain text rule off, so labels, boxes and code
  colours were missing. Now each line gets the rules by its kind. File names, paths and names
  such as `BASICLY_REF` draw as code, a label inside a numbered line draws bold, and a closing
  question draws in a note box. The head names the sender, `ask` or `note` and the line count,
  with `copy` at its right. A long message draws whole in the tab, with no fold row.
