- **reply-view copies a block of the last reply from the keyboard.** `/replies copy diagram`,
  `/replies copy table` and `/replies copy code` copy the last block of that kind in the last
  reply, the same text that the button of the block copies, and the toast names it.
  `/replies copy reply` copies the whole reply. When the last reply has no block of that kind,
  the command says so and names `/replies copy reply` (handily-5zzxk.9).
