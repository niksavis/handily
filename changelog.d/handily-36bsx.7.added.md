- **State, class and ER diagrams draw in the terminal.** reply-view draws a mermaid
  `stateDiagram` with the layout of a flowchart, `●` for a start and `◉` for an end. A
  `classDiagram` draws each class with its name and up to 10 members, `△`, `◆` or `◇` under the
  parent or the owner, an arrow head for an association, and the cardinalities and labels as
  words. An `erDiagram` draws its entities top to bottom, with each cardinality as `1`, `0..1`,
  `0..n` or `1..n`. Nested states, a fork, a join, a choice and other syntax that does not draw
  yet show the source under a note that names the reason. The desktop app shows each drawing in a
  plain code block, as it shows a flowchart (handily-36bsx.7).
