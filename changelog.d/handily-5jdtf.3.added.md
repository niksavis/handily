- **The board draws its marks from the Glyphs setting.** With Glyphs `nerd`, the this session
  tab, the this machine tab, the task band, the plan line and the task rows in the transcript of
  `handily-board` draw the Nerd Font icons in a terminal. The agent lanes end in the icon of
  their state, and the status line and `/board stats` use the bell icon. Each icon takes the
  place of one plain mark, so every line keeps its width. The running call mark `▸`, the
  progress bar, the gate strip, the lane cells, the rules and the row bullet `●` stay the same.
  The desktop app draws plain, whatever the setting is. An open pane draws again after a change
  of the setting in `/config` (handily-5jdtf.3).
