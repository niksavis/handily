- **The message tab draws a message from another session as structured text.** In the terminal,
  the `message` tab that opens on `more` draws paragraphs, numbered lists, bold labels, warning and
  note boxes, and record ids, tags, commits and links in their own colours. A message with markdown
  draws as a reply does, and a message that looks like a log draws its lines as sent. No word is
  changed, and `copy` copies the message as it was sent. (handily-qv5sb8)
