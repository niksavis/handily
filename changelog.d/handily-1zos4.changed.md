- **handily-reply-view 0.3.1 separates the rows of a wrapped table and underlines the
  headings.** When a cell of a table wraps, one blank line separates the rows, so you can see
  where each row ends. A table where no cell wraps has no blank lines. Each heading stays bold
  and is now underlined. The underline covers the text of the heading, not the space between
  the columns, and it adds no line. A blank line counts as a line when a long reply folds
  (handily-1zos4).
