- **Markdown and diff blocks draw in their own colours.** On the terminal, reply-view colours a
  block with the tag `md`, `markdown`, `diff` or `patch` itself, because the code element of
  Claude Code draws them with no colour. Headings, list marks, quotes, code spans and links of
  Markdown, and the file lines, hunk lines, added lines and removed lines of a diff take the
  roles of the reply. Other languages still go to the code element (handily-dnjvgf).
