- **Tables and diagrams in a reply draw in colour, and a table can draw in a box.** The header
  cells of a table are bold in the theme colour `claude`, the rules are in `subtle`, and a cell
  that holds only a number is in `planMode`. A cell shows inline code in `permission`, bold text
  bold and a link underlined in `suggestion`, without the markdown marks. The rule under the
  header is now a double rule, `═╪═`. The new setting Table style draws a full box with `box`
  at 40 columns or more. The default `rules` keeps the layout without a box. A stored value that
  is neither option draws `rules`, and the debug log names the value. On the terminal, the boxes
  of a diagram take `suggestion`, `planMode` and `merged` in turn, the arrow heads are in
  `claude`, and the lines and labels are in `inactive`. `copy drawing` copies the plain lines.
  The desktop app draws a diagram in a code block, as before (handily-9seiy.1).
