- **A wide drawing in a code block keeps its columns.** In reply-view, a code block with
  box-drawing characters or an ASCII rule such as `+---+` that is wider than the reply no longer
  wraps. Each line stays on one row and is cut at the edge with `…`, and one dim note above the
  block names the width and says `Widen the window to see this drawing.` `copy` copies the
  block as written. A code block with no drawing, such as a long shell command, wraps as before.
  (handily-2dpxv0.25)
