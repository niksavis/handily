- **Claude can recommend an option or an answer, and you accept it with one click or one
  word.** `task_assign` takes `recommended`: an option number for a decide task, or one line
  for an answer task. In handily-board, the For you row draws the recommended option first as
  `[ ★ go ]` with the word `recommended`, and an answer task shows the recommended answer with
  `[ accept ]`. One press sends it. A prompt of only `go`, `yes`, `ok` or an option number
  tells Claude which task it accepts, or to ask which one when two or more match. `task_list`
  shows the recommendation on the row. (handily-psv8fp)
